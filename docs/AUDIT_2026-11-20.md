## P5: Copy quality

- **One word per concept.** "disciplines", "topics", "categories" and "entries" are all used for the same thing.
  - Pick **topics** and **lessons**.
  - Affected: `learn/page.tsx:30,36`, `about/page.tsx:16,60`, `skill-map/SkillMapClient.tsx:73,80`, `profile/ProfileClient.tsx:202`, `interview-prep/page.tsx:107,184,194`.
- **Slop and eyebrows.** Suggested replacements:

  | Location | Current | Suggested |
  |---|---|---|
  | `learn/page.tsx:36` | "Every entry, by discipline" | remove |
  | `ProjectCard.tsx:344` | "Specimens to review" | "Examples to review" |
  | `AchievementsClient.tsx:109` | "Your journey starts here" | "No badges yet" |

- **Dead code.** `src/components/home/HeroWarm.tsx` is imported nowhere. It also holds the only live `dark:` class and hardcoded lesson counts. Delete it.
